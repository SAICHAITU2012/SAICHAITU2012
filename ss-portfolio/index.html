about // operator profile

I'm S. SadhaSri — a software developer and creative engineer based in India, working at the intersection of delightful web interfaces and practical machine learning. I care about software that feels considered: intentional color, accessible typography, micro-interactions that respond like physical objects.

On the data side I run end-to-end pipelines — cleansing, feature engineering, modeling, evaluation — on real-world datasets, from multi-station air-quality time series to student-wellness surveys. On the tooling side I automate the developer experience itself: generators that compile web UIs into agent-readable SKILL.md specs, and bridges that pipe Telegram straight into local AI coding sessions.
